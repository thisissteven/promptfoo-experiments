# Findings 11-18-2026

# 2026-11-18 发现

## This week: API surface mapping

## 本周：API 面梳理

This week’s result is reconnaissance, not a vulnerability finding. I mapped two
public API surfaces: the Bambu Lab wiki GraphQL API and the storefront API used by
the US store. No critical or confirmed attack surface was found: public queries
return metadata, protected queries are gated, and store guest endpoints are
expected but did not expose cross-account data.

本周的结果是侦察，不是漏洞发现。我梳理了两个公开 API 面：Bambu Lab wiki GraphQL
API 和 US 商店使用的前端 API。未发现严重或已确认的攻击面：公开查询只返回元数据，
受保护查询被鉴权，商店访客端点符合预期且未暴露跨账号数据。

### How the queries/endpoints were found

### 查询/端点的发现方式

- **Wiki:** the public Wiki.js client exposes `POST /graphql`. GraphQL
  introspection is disabled, so field names were discovered from Apollo
  validation suggestions and direct field tests.
- **Store:** the public Next.js JS chunks loaded by `us.store.bambulab.com` (from
  `store-fe.bblcdn.com`) contain the API host and route strings:
  `na-store-api.bambulab.com`, `/mall-order/v1/*`, `/mall-userms/user/*`. Store
  source maps are `403`; the chunks themselves are public.

- **Wiki：**公开的 Wiki.js 客户端暴露 `POST /graphql`。GraphQL introspection 已
  禁用，因此通过 Apollo 校验提示和直接字段测试发现字段。
- **商店：**`us.store.bambulab.com` 加载的公开 Next.js JS chunk（来自
  `store-fe.bblcdn.com`）包含 API 主机和路由字符串：
  `na-store-api.bambulab.com`、`/mall-order/v1/*`、`/mall-userms/user/*`。商店
  source map 为 `403`；chunk 本身公开。

### What could make it an attack surface

### 什么情况下会成为攻击面

- **Wiki:** if a resolver lost its auth directive, page visibility were
  misconfigured, or self-registration were enabled; then private content or
  mutations could be reachable. Current results: `PageViewForbidden`,
  `Forbidden`, `AuthRequired`; registration is disabled.
- **Store:** if the client-controlled `x-bbl-account-access`, cart/quantity, or
  `cartSubtotal` were trusted for another account or the payment amount; or if
  address/order/review endpoints lacked ownership checks. Current results:
  guest endpoints only, address/subscribe gated (`40100`), cart add
  business-blocked (`10012`), own `cusId` did not match a store user.

- **Wiki：**如果某个 resolver 丢失鉴权指令、页面可见性配置错误或开放注册，私有
  内容或 mutation 就可能可达。当前结果：`PageViewForbidden`、`Forbidden`、
  `AuthRequired`；注册已禁用。
- **商店：**如果客户端可控的 `x-bbl-account-access`、购物车/数量或
  `cartSubtotal` 被用于其他账号或支付金额；或地址/订单/评价端点缺少归属校验。
  当前结果：仅访客端点，地址/订阅被鉴权（`40100`），加购被业务规则拒绝
  （`10012`），自己的 `cusId` 未匹配商店用户。

### Store API

Host: `na-store-api.bambulab.com` (US store; bundle also references
`eu-store-api`, `ap-store-api`, `mx-store-api`).

主机：`na-store-api.bambulab.com`（US 商店；bundle 还引用 `eu-store-api`、
`ap-store-api`、`mx-store-api`）。

| Endpoint | Method | Observed | Auth-gated |
|---|---|---|---|
| `/mall-order/v1/cart/size` | GET | `200 {"code":1,"data":{"cartSize":0}}` | No (guest) |
| `/mall-order/v1/cart/add` | POST | `200 {"code":10012,"message":"Some products cannot be added..."}` | No (business rule) |
| `/mall-order/v1/checkout/token/create` | POST | `200 {"code":1,"data":{"token":null,...}}` | No (guest; empty cart) |
| `/mall-userms/user/ms/user/info` | GET | `200 {"code":1,...}`; new 18-digit guest `userId` per call | No (guest) |
| `/mall-userms/user/shippingAddress/queryList` | GET | `200 {"code":40100,"message":"Unauthorized"}` | **Yes** |
| `/mall-userms/user/profile/subscribeDiscountCode` | POST | `200 {"code":40100,"message":"Unauthorized"}` | **Yes** |
| `/mall-userms/user/ms/email/market/v2` | POST | `200 {"code":10012,"message":"System busy..."}` | Inconclusive |
| `/actuator`, `/actuator/health`, `/v3/api-docs`, `/swagger-ui` | GET | `403` / `404` | Not exposed |

Client-identified but not individually tested: `cart/lightweight/modify`,
`cart/merge`, `checkout/buy/now/token/create`, `checkout/partial/token/create`,
`shippingAddress/add`, `review/submit`, `feedback/add`.

前端 bundle 中存在但未单独测试：`cart/lightweight/modify`、`cart/merge`、
`checkout/buy/now/token/create`、`checkout/partial/token/create`、
`shippingAddress/add`、`review/submit`、`feedback/add`。

**Current conclusion:** no confirmed attack surface. Wiki content/mutations are
gated; store guest endpoints are expected, address/subscription endpoints are
gated, and no cross-account data was observed.

**当前结论：**没有已确认的攻击面。Wiki 内容/mutation 被鉴权；商店访客端点符合预期，
地址/订阅端点已鉴权，未观察到跨账号数据。
