===== Page 1 =====

本周，我试图寻找更多关于BambuLab聊天机器人背后所运行代理（HiAgent）的信息。我找到了这个产品联系页面，看起来该产品仅面向潜在企业客户，而不是个人测试者或学生。

[图片/截图]

Another finding is that HiAgent provides a python SDK for working with their product, github link: https://github.com/volcengine/hiagent-python-sdk

另一个发现是，HiAgent提供了一个用于操作其产品的Python SDK，GitHub链接：https://github.com/volcengine/hiagent-python-sdk

Some services provided in the SDK:

1. ChatService: sends messages to a chat agent.

2. KnowledgebaseService: manages and queries knowledge bases.

3. ToolService: runs tools and workflows.

4. KnowledgeRetriever: gets content from datasets.

5. Agent: starts and manages an agent session.

SDK中提供的一些服务：

1. ChatService:向聊天代理发送消息。

2. KnowledgebaseService:管理和查询知识库。

3. ToolService:运行工具和工作流。

4. KnowledgeRetriever:从数据集中获取内容。

5. Agent:启动和管理代理会话。

Nothing new here, we know that bambulab chatbot has access to knowledge bases and can call registered tools. Potentially, we can run our own HiAgent and do tests on it. The only thing missing is a valid HiAgent sandbox URL and other HiAgent credentials in order to use the SDK (HIAGENT_TOP_ENDPOINT, HIAGENT_AGENT_APP_KEY, etc.)

这里没有什么新内容，我们知道BambuLab聊天机器人可以访问知识库，并且可以调用已注册的工具。可能的话，我们可以运行自己的HiAgent并在其上做测试。唯一缺少的是一个有效的HiAgent沙箱URL和其他HiAgent凭据，以便使用SDK（HIAGENT_TOP_ENDPOINT、HIAGENT_AGENT_APP_KEY等）。

HiAgent also provides a cli- anything- hiagent cli tool for tracing integration. Using the tool, we can inspect the following trace data:

Which tools the agent called. What documents the agent retrieved. How the agent assembled the prompt. What the model outputs.

HiAgent还提供了一个cli- anything- hiagent命令行工具，用于追踪集成。使用该工具，我们可以检查以下追踪数据：

代理调用了哪些工具。代理检索了哪些文档。代理如何组装提示词。模型输出了什么。

To use the cli tool, we also need a few environment variables that can only be obtained in the HiAgent console: export VOLC_ACCESSKEY \(\equiv\) export VOLC_SECRETKEY \(\equiv\)

要使用cli工具，我们还需要一些只能在HiAgent控制台中获取的环境变量：export VOLC_ACCESSKEY \(\equiv\) export VOLC_SECRETKEY \(\equiv\)

===== Page 3 =====

Another finding is that the chatbot's knowledge base contains exactly the same information as the wiki. It has no access to the publicly available user comments, so there is no risk of indirect prompt injection as the wiki is probably maintained by the internal staff of bambulab.

另一个发现是，聊天机器人的知识库包含与Wiki完全相同的信息。它无法访问公开的用户评论，因此不存在间接提示注入的风险，因为该Wiki很可能由BambuLab的内部员工维护。
